05 / METHODOLOGY

What the evidence means

A completed retargeting file is a useful result, with clearly bounded claims.

01

Bind inputs

Robot configuration, source motion, correspondence slots, and code are hashed. The execution plan is approved by its exact hash.

02

Verify output

Completed NPZ files are checked for finite G1 poses, frame count, FPS, and a matching playback model.

03

Diagnose motion

MuJoCo joint layout drives limit and velocity checks. Warnings highlight frames for human review.

Current boundary

Foot contact, foot skating, physical feasibility, and visual quality are not established by these automated reports. The AI assistant reads completed records only; it is not an autonomous execution agent or remote robot controller.
